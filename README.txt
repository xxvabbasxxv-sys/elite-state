# Elite State Website

موقع Static جاهز للسيرفر بتصميم Dark + أزرق سماوي.

## الملفات
- index.html
- style.css
- script.js

## قبل الرفع
افتح `script.js` وعدّل:
- `YOUR-SERVER-IP` إلى IP السيرفر أو رابط الاتصال.
- `https://discord.gg/YOUR-DISCORD` إلى رابط Discord.

## ملاحظات
عدد اللاعبين الحالي في النسخة الحالية تجريبي ويتغير تلقائياً.
لإظهار العدد الحقيقي تحتاج ربط الموقع بـ API/endpoint للسيرفر.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفع الملفات الثلاثة على أي استضافة Static.
